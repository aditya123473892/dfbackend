Talk to God is limited to non-graphic adult fantasies, desires, intimacy, sex life, sexual wellbeing, and consent, boundaries or emotions directly related to those topics. Unrelated questions and mixed requests get a fixed redirect. App help is no longer retrieved.

Every AI turn uses deterministic safety/secret checks, a separate input scope classification, generation with the restricted persona, deterministic output checks, and a separate classification of the full generated reply. Scope decisions accept only exact labels; outages, timeouts or malformed decisions return 503 so the member can retry. There is no configuration switch to bypass scope checks. The existing backend DeepSeek configuration is used; no extra library or API key is required.

Greetings, privacy questions and relevant short follow-ups are supported. Urgent safety support takes priority. Staff may still answer directly; when a session returns to AI, the same guardrails apply. Refused exchanges stay in staff-visible history with flags but are excluded from future AI context and summaries.

Each allowed turn adds two small classifier calls, capped at 10 seconds each. Summarisation is also capped at 10 seconds; the member client and local proxy allow 165 seconds for the complete turn with the default 120-second generation timeout. Deployments with longer generation timeouts must adjust their client/proxy request budgets too.

Run `npm test -- --runInBand god-chat` for offline regression checks, and `npm run test:integration -- --runTestsByPath test/integration/god-chat-sessions.int-spec.ts` for session persistence and handoff checks. After `npm run build`, run `node scripts/evaluate-god-chat-scope.cjs` for an opt-in live evaluation using synthetic messages and the backend credentials. This sends 20 small classifier requests to the configured provider. Offline tests mock classification decisions and verify enforcement; the live evaluation checks the provider's actual decisions. Semantic classification is probabilistic, so rerun the live evaluation when changing models or policy wording.
